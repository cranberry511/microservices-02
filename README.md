## Решение 2

| Возможности              |  Apache Kafka |   Rabbit MQ     |    ActiveMQ      |
|--------------------------|---------------|-----------------|------------------|
| Облачный                 |      нет      |       нет       |       нет        |
| Сложная маршрутизация    |      нет      |       Да        |       Да         |
| Высокая скорость работы  | Очень высокая |     Средняя     |     Средняя      |
| Разделение прав доступа  |      Да       |       Да        |       Да         |
| Поддержка разных форматов|      Да       |       Да        |       Да         |
| Поддержка кластеризации  |      Да       |       Да        |       Да         |
| Хранение на диске        |      Да       |       Да        |       Да         |
| Простота эксплуатации    |    Средняя    |       Да        |     Средняя      |

Если приоритетом является простота эксплуатации, то RabbitMQ может быть хорошим выбором, особенно для менее сложных сценариев.
Однако, из-за особенностей сценариев прикладной части, может потребоваться и Apache Kafka.
